# Pat&Mat Studio X

Stwórz mi najbardziej innowacyjną i nowoczesną stronę, z animacjami, ruchomymi elementami i wszystko co możesz tam daj. Strona ma przedstawiać firmę Pat&Mat.corp która zajmuje się marketingiem od a do z. Takie Creative Studio o nazwie Pat&Mat.corp. Pokaż co potrafisz zrobić. Ma być to nowoczesne, estetyczne, profesjonalne. Możesz trochę nawiązać do designu Apple czyli liquid glass. Ale mają być interaktywne animacje i nowoczesne rozwiązania.
